For landlords with 1–20 doors

Smart locks for landlords

A turnover is the cheapest time to stop using the key you handed the last tenant. In Louisville, Jeffersonville, New Albany, and Clarksville the choice is usually one of three: rekey what you have, put a keypad on the deadbolt, or install a lock you can code from your phone.

Rekey when the hardware is fine

If the bolt throws and the cylinder is not worn out, a rekey makes the old key useless. Do every exterior door, including the garage service door. A lockbox for vendors does not replace that step. Example rekey-kit prices are in the locks section, in a separate eBay block and Walmart block.

Keypad deadbolt

A keypad with a key backup is the usual first upgrade. You can give a cleaner a code and delete it the same day. Batteries die, so the physical key still matters, and so does telling the tenant which code is theirs. Codes are not a substitute for a lease.

Wi-Fi or Z-Wave

Wi-Fi locks need a signal at the door. Brick and metal doors in older Louisville houses often do not have one, and the lock then fails “offline” the week you need a code. Z-Wave and similar radios need a hub on the network; they are a better fit when you already run one, and a worse fit when you do not want a hub in every unit. Either way, plan for a battery calendar. Questions

Which smart lock should I buy?

Pick the radio you can actually support, then compare the current eBay block with the current Walmart block. Do not expect a 30-day low. Those are turned off.

Is a rekey enough between tenants?

Yes, when you rekey every exterior cylinder the old tenant could have used. Replace the lock if it is broken, stuck, or missing.

Who installs it?

A handy owner can hang a residential keypad. For a lockout or a storefront, ask for locksmith quotes.
